# FPS 灵敏度检测实验室（FPS Sensitivity Lab）

一个**纯前端、可在浏览器中真实操作**的 FPS 射击灵敏度检测系统。不是静态统计页面：
系统真实监听鼠标移动 / 点击 / 按住开火，通过 Canvas 互动测试采集数据，计算命中率、反应时间、
转向偏差、跟踪稳定性与压枪控制，并根据**每次的实际测量结果**生成建议。

## 快速开始

```bash
# 1. 安装依赖（Node.js 18+）
npm install

# 2. 启动开发服务器（会自动打开浏览器）
npm run dev
```

浏览器访问终端输出的地址（默认 http://localhost:5173）。

其它命令：

```bash
npm run build     # 构建生产版本到 dist/
npm run preview   # 预览生产构建（自动打开浏览器）
npm test          # 运行 Vitest 单元 / 逻辑测试（jsdom）
npm run e2e       # 运行 Playwright 真实浏览器端到端走查（先 build）
```

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 开始页面 | 项目介绍、五项测试入口、当前校准 / 记录状态 |
| 基础设置 | 鼠标 DPI、游戏灵敏度、FOV、显示器比例、测试时长 / 目标大小 / 速度 / 难度；恢复默认、清空本地数据；localStorage 持久化 |
| 鼠标校准 | Pointer Lock 下完成 90° / 180° / 360° 转身，记录鼠标像素移动、视角变化、物理距离（可填实测厘米）与完成时间，保存 cm/360；浏览器不支持时显示明确提示 |
| 快速点击 | 随机位置 / 大小 / 间隔出现目标，统计命中率、平均 / 最快反应、漏点、空白误点 |
| 快速转向 | 目标出现在视野不同方向，记录过转 / 欠转、完成时间、命中，并给出偏向结论 |
| 目标跟踪 | 目标持续变速变向移动，按采样帧统计在靶率、偏离时间、平均偏差与鼠标移动抖动，而不是只看最后是否点中 |
| 压枪稳定 | 按住左键持续开火，准星受后坐力上跳，记录控制率、平均偏移、受控时长及前 / 后半段差异，画布显示稳定圈与移动轨迹 |
| 灵敏度对比 | 保存多组灵敏度方案，用相同测试、相同种子（相同目标规则）、相同时长分别测试，逐项对比命中 / 反应 / 转向 / 跟踪 |
| 结果页面 | 综合分环形图、全部细项指标、基于数据的多条建议，可重新测试或返回设置 |
| 测试记录 | 最近 100 次记录持久化，查看完整结果、删除单条、清空全部、导出 JSON / CSV，数据损坏显示错误提示 |

测试开始前有 3 秒倒计时；测试中顶部实时显示剩余时间与进度条；支持暂停 / 继续 / 重新开始；
进行中退出会先自动暂停并二次确认，避免误触丢失结果。

## 操作说明

- **快速点击**：无需锁定鼠标，直接移动并点击目标。
- **快速转向 / 目标跟踪 / 压枪**：点击“开始测试”后浏览器会请求鼠标锁定（Pointer Lock），
  按 Esc 解锁会自动暂停。不支持锁定的环境会回退为普通鼠标移动。
- **压枪**：进入测试后**按住鼠标左键**即持续开火，向下移动鼠标抵消上跳。
- **校准**：锁定鼠标后平稳转动到目标角度，按空格或“完成转身”；可用尺子输入物理距离得到更准的 cm/360。

## 测试

- `npm test`：16 个用例，覆盖设置规范化与持久化、灵敏度 / 校准换算、可复现随机数、
  目标生成、命中 / 失误 / 漏点判定、反应时间、过 / 欠转、跟踪在靶率、压枪前后半段、
  评分、建议生成、记录增删与数据损坏处理。
- `npm run e2e`：Playwright Chromium 真实浏览器中完成一次校准、快速点击、快速转向、
  目标跟踪、压枪，以及记录查看 / 导出 / 删除 / 刷新持久化的完整走查。

## 数据与隐私

所有设置、校准与测试记录仅保存在当前浏览器的 localStorage 中，不会上传到任何服务器。
在“设置”页可一键清空全部本地数据。
