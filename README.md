# FPS 射击灵敏度检测系统

一个运行在浏览器中的交互式 FPS 灵敏度测试工具。它不是静态统计页：系统通过 Pointer Lock 与 Pointer Events **真实记录鼠标移动、点击与按压**，提供鼠标校准、快速点击、快速转向、移动目标跟踪、压枪稳定性五项实时测试，并根据实测数据给出命中、反应、转向、跟踪、压枪五个维度的评分与可执行的灵敏度调整建议。

## 环境要求

- Node.js 18 及以上（开发环境使用 Node 22 验证）
- 桌面浏览器：Chrome / Edge / Firefox（需支持 Pointer Events 与 Pointer Lock；不支持时页面会显示明确提示）

## 启动方式

```bash
# 1. 安装依赖（首次）
npm install

# 2. 启动开发服务器并自动打开浏览器
npm start
# 等价于 npx vite --open，默认地址 http://localhost:5173

# 不自动开浏览器的启动方式
npm run dev

# 生产构建与本地预览
npm run build
npm run preview
```

## 测试

```bash
# 单元测试（Vitest + jsdom）：鼠标移动记录、目标生成、命中判断、
# 反应时间、分数计算、设置保存、测试记录、CSV 导出、方案对比
npm test

# 端到端测试（Playwright + 真实 Chromium）：
# 自动完成一次校准、快速点击、转向、跟踪、压枪，以及记录导出/暂停
npx playwright install chromium   # 首次需要下载浏览器
npm run e2e
```

## 使用流程

1. **设置**：填写鼠标 DPI、游戏灵敏度、FOV、显示器比例，选择测试时间、目标大小、目标速度、难度。设置自动保存到 localStorage，刷新不丢失；可恢复默认或清空全部本地数据。
2. **校准**：选择 90° / 180° / 360° 转身，进入鼠标锁定后水平移动鼠标再单击结束。系统记录移动像素、视角变化与用时，换算出 cm/360° 并用于转向测试的角度换算。
3. **测试**：开始前有 3 秒倒计时；HUD 显示剩余时间与进度条；支持暂停 / 继续 / 重新开始 / 退出（进行中退出有确认，防止误触丢结果）。
4. **结果**：命中率、反应时间、移动距离、失误、转向偏差、跟踪稳定性、综合分数与等级，以及**依据本次测量值生成**的调整建议（偏快/偏慢/过头/不足/稳定），可重新测试或返回设置。
5. **记录与对比**：最近 100 条记录持久化保存，可查看单次详情、删除单条、清空、导出 JSON/CSV；可保存多组命名灵敏度方案，用相同规则分别测试后按方案对比命中、反应、转向、跟踪、压枪的差异。

## 数据与隐私

所有数据仅保存在浏览器 localStorage 中，不经过任何服务器。若本地数据损坏，系统会在设置/首页显示明确的错误横幅，可一键清空损坏数据后重新开始。

设置页提供「备份与恢复」：一键导出包含设置、全部记录和灵敏度方案的版本化 JSON 备份（`format: fps-sensitivity-backup`, `version: 1`）；导入时先解析校验并展示差异预览（版本、导出时间、设置变化、有效/无效/新增/重复记录数、方案数），支持「替换全部」与「合并新增」两种模式，确认后通过统一入口原子写入三个存储键，任一写入失败自动回滚到导入前快照，成功后重新初始化应用。
